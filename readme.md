# Projekts: Abonementa Izvēles Kalkulators

### Apraksts
Šī ir interaktīva mājaslapa, kas ļauj lietotājam izvēlēties aplikācijas abonēšanas periodu (mēnesis vai gads) un uzreiz redzēt aprēķināto cenu un ietaupījumu.

### Funkcionalitāte
- Perioda izvēle no saraksta.
- Datu validācija (pārbaude, vai ir veikta izvēle).
- Salīdzinājums starp mēneša un gada maksu.
- Dinamiska satura atjaunošana ar JavaScript.

### Izmantošana
Atveriet `index.html` failu jebkurā pārlūkprogrammā.
